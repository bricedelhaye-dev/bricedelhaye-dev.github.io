# Méthode unifiée — Le Quai joue
Version : 2026-08-23
Statut : ACTIVE POUR LE PILOTAGE

## Principe
La méthode historique V6/V6.2 n'est pas remplacée : elle constitue le squelette des portes produit.
La gouvernance IA ajoutée en août 2026 devient la couche de contrôle qui rend ces portes persistantes,
vérifiables entre ChatGPT, Figma, Codex, GitHub et l'utilisateur.

## Chaîne canonique
**CADRER → EXPLORER → ÉVALUER → ATTAQUER → DÉCIDER → INTÉGRER → PROUVER → APPRENDRE**

Elle complète la formulation historique :
**EXPLORATION → ÉVALUATION → DÉCISION → INTÉGRATION**
sans la contredire.

## Couche G — gouvernance préalable
- G0 — Plan total structuré.
- G1 — Angles morts recherchés et registre créé.
- G2 — Méthodes unifiées et hiérarchie des sources définie.
- G3 — Gouvernance persistante installée dans GitHub sur branche isolée.
- G4 — Preuve de permissions/outils et retour Codex validés.

Aucune porte P ne peut être rouverte avant G4.

## Couche P — portes historiques produit
Les sens historiques sont conservés :
- P0 — intégrité / références historiques ;
- P1 — méthode canonique ;
- P2 — patrimoine / invariants / dettes ;
- P3 — cadrage global ;
- P4 — exploration / conception ;
- P5 — évaluation + contradiction ;
- P6 — intégration sur copie ;
- P7 — preuves laboratoire ;
- P8 — utilisateur réel / Android réel ;
- P9 — backend / multi-appareils / terrain ;
- P10 — publication.

## Important : statuts anciens
Les statuts P0–P10 enregistrés en août 2026 sont des **preuves historiques**.
Ils ne sont pas automatiquement les statuts du futur audit.
L'audit à venir devra les confirmer, les reclasser ou les invalider explicitement.

## Règle anti-saut
Un succès dans une dimension ne franchit jamais implicitement une autre porte.

## Règle de preuve visible
Toute porte qui change de statut doit avoir :
- source / preuve ;
- verdict ;
- diff ou comparaison si applicable ;
- checkpoint ;
- prochain acte autorisé.

## Règle d'apprentissage
Toute erreur répétable doit produire au moins un changement durable :
test, documentation, règle, outil, garde-fou ou procédure.
