# Preflight
Avant toute action importante :
- phase et porte confirmées ;
- source de vérité fraîche ;
- objectif/non-objectifs ;
- critères avant modification ;
- périmètre ;
- actifs/fonctions protégés ;
- permissions réelles de l'outil ;
- checkpoint/rollback ;
- preuve attendue ;
- tests attendus.
Une case critique manquante = BLOQUÉ.
