# Invariants de gouvernance
Statut : ACTIF — pré-audit

- Brice = intention et arbitrage humain.
- ChatGPT = orchestration, audit, planification et contrôle.
- Figma = vérité visuelle et interactionnelle.
- Codex = exécution technique.
- GitHub = mémoire durable et versionnée.
- Tests/revues = preuves.
- Aucune IA n'est supposée connaître automatiquement le contexte d'une autre.
- Aucune étape importante sans critères définis avant modification.
- Aucune porte sans preuve visible et checkpoint.
- Aucun contrôle en échec ne peut être contourné.
- Une règle historique ne devient pas active sans confirmation dans l'état courant.
