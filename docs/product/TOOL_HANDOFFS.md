# Contrats entre outils
ChatGPT → Figma : cible, contraintes, références, critères, états.
Figma → Codex : node exact, composants, variables, comportements, breakpoints.
ChatGPT → Codex : contexte autonome, critères, tests, rollback.
Codex → ChatGPT : diff, tests, écarts, risques, permissions observées.
ChatGPT → Brice : preuve visible + question minimale si nécessaire.
